# GymLog Web

Sistema web para gerenciamento de alunos e treinos voltado para personal trainers.

## 🎯 Objetivo

O GymLog Web tem como objetivo auxiliar personal trainers no gerenciamento de seus alunos, treinos, exercícios e acompanhamento de evolução.

## 🚀 Tecnologias

- Next.js
- React
- TypeScript
- CSS
- Git
- GitHub

## 📋 Funcionalidades

- [ ] Login
- [ ] Dashboard
- [ ] Gerenciamento de alunos
- [ ] Gerenciamento de exercícios
- [ ] Gerenciamento de treinos
- [ ] Acompanhamento da evolução
- [ ] Estatísticas
- [ ] Tema claro/escuro
